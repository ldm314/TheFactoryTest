# Running Factory Test

Generated by The Factory. This file, `app.py`, `flags.json`, the `Dockerfile`
and `docker-compose.yml` are regenerated whenever the application gains or
changes a component — edits to them are lost.

## With a database

```
docker compose up --build
curl localhost:8080/health
```

## Without

```
DATABASE_URL=postgresql://... python app.py
```

Every component of this application answers on one port. `GET /health` lists
them and reports which flags are on.

## Components

- `bookmarks.py` serves `/bookmarks` — the system shall list every bookmark for the owner
- `comments.py` serves `/comments` — the system shall store a comment and return it by id
- `memos.py` serves `/memos` — the system shall store a memo and return it by id
- `notes.py` serves `/notes` — the system shall store a note and return it by id
- `owners.py` serves `/owners` — the system shall Store a bookmark with its url and return it to its owner by id
- `reminders.py` serves `/reminders` — the system shall store a reminder and return it by id

## Flags

A component is **dark** from the moment its code merges until an engineer
accepts the requirement and promotes its flag (docs/09 D-26). A route behind a
flag that is off answers `404`: the endpoint does not exist as far as a caller
can tell. `flags.json` is the state, and it is written by a release — one commit
per promotion, carrying the work item that caused it.
